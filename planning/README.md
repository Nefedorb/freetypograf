# Planning

Рабочие планы проекта хранятся здесь. Этот каталог является единственным местом для текущих планов выполнения, session-файлов и кратких workflow-заметок.

## Активная задача

MVP desktop-приложения FreeTypograf для Windows и macOS:

- Tauri 2 + статический Next.js UI.
- Локальная обработка текста через `typograf` и безопасную ёфикацию.
- Floating-кнопка поверх окон, tray-меню и hotkey.
- Clipboard-flow для выделенного текста в сторонних приложениях.

## Критерии готовности MVP

- Приложение собирается для Windows и macOS через GitHub Actions.
- Настройки открываются из floating-кнопки и tray.
- Выделенный текст типографируется локально и вставляется обратно как plain text.
- Текст пользователя не отправляется наружу и не пишется в логи.
- macOS Accessibility-разрешение объяснено и требуется только для отправки copy/paste по действию пользователя.
- Есть минимальные тесты для правил типографики, настроек и clipboard-flow.
