# Инструкция для тестировщика на MacBook

## Как получить приложение

1. Откройте репозиторий `Nefedorb/freetypograf` на GitHub.
2. Перейдите во вкладку **Actions**.
3. Откройте последний успешный workflow **Build macOS**.
4. Внизу страницы скачайте artifact `typograf-macos-dmg`.
5. Распакуйте скачанный zip и откройте `.dmg`.

## Первый запуск

Сборка тестовая и не подписана Apple Developer ID, поэтому macOS может показать предупреждение.

1. Откройте `.dmg`.
2. Перетащите `Typograf.app` в `Applications`, если macOS предлагает это сделать.
3. Запустите приложение через правый клик по `Typograf.app` -> **Open**.
4. Если macOS снова предупреждает о неизвестном разработчике, подтвердите запуск через **Open**.

## Accessibility-разрешение

Для типографирования выделенного текста приложению нужен доступ Accessibility: оно отправляет `Command+C` и `Command+V` только по вашему действию.

1. Откройте **System Settings**.
2. Перейдите в **Privacy & Security** -> **Accessibility**.
3. Включите разрешение для `Typograf`.
4. Если приложения нет в списке, добавьте его кнопкой `+`.

## Что проверить

- Открывается окно настроек.
- В menu bar/tray есть меню приложения.
- Плавающая кнопка видна поверх окон.
- Один клик по плавающей кнопке типографирует выделенный plain text.
- Двойной клик по плавающей кнопке открывает настройки.
- Хоткей `Command+Shift+T` запускает типографирование.
- Крестик над плавающей кнопкой скрывает ее, а вернуть ее можно из меню.
- Текст не появляется в логах и не отправляется наружу.

## Если приложение не запускается

Для тестовой unsigned-сборки macOS иногда сохраняет quarantine-флаг. Технический пользователь может снять его командой:

```bash
xattr -dr com.apple.quarantine /Applications/Typograf.app
```

Обычному пользователю лучше сначала попробовать запуск через правый клик -> **Open**.
