# macOS Testing

## Как получить приложение

Лучший способ для обычного тестировщика:

1. Откройте страницу [Releases](https://github.com/Nefedorb/freetypograf/releases).
2. Выберите последний release.
3. Скачайте файл `.dmg`.
4. Откройте `.dmg` и перенесите `FreeTypograf.app` в `Applications`, если macOS это предлагает.

Если release ещё не создан, можно скачать тестовый artifact:

1. Откройте [Actions](https://github.com/Nefedorb/freetypograf/actions).
2. Выберите последний успешный workflow **Build macOS**.
3. Внизу страницы скачайте artifact `freetypograf-macos-dmg`.
4. Распакуйте zip и откройте `.dmg`.

## Первый запуск unsigned-сборки

Сборка пока не подписана Apple Developer ID, поэтому macOS может показать предупреждение.

1. Откройте `.dmg`.
2. Перенесите приложение в `Applications`.
3. Запустите приложение через правый клик по `FreeTypograf.app` -> **Open**.
4. Если macOS снова предупреждает о неизвестном разработчике, подтвердите запуск через **Open**.

## Accessibility Permission

FreeTypograf типографирует выделенный текст через clipboard-flow. Для этого macOS должна разрешить приложению отправлять `Command+C` и `Command+V` по вашему действию.

1. Откройте **System Settings**.
2. Перейдите в **Privacy & Security** -> **Accessibility**.
3. Включите разрешение для `FreeTypograf`.
4. Если приложения нет в списке, добавьте его кнопкой `+`.

Приложение не отправляет текст наружу и не пишет содержимое clipboard в логи.

## Чеклист

- Открывается окно настроек.
- В menu bar/tray есть меню приложения.
- Floating-кнопка видна поверх окон.
- Один клик по floating-кнопке типографирует выделенный plain text.
- Двойной клик по floating-кнопке открывает настройки.
- Крестик снаружи круга скрывает floating-кнопку только по явному клику и не мешает перетаскиванию.
- Хоткей `Command+Shift+T` запускает типографирование.
- Floating-кнопку можно скрыть и вернуть через меню или настройки.
- Кнопка «Сбросить позицию» возвращает её в рабочую область, если она была перетащена к краю экрана.
- Текст не появляется в логах и не отправляется наружу.

## Если приложение не запускается

Для тестовой unsigned-сборки macOS иногда сохраняет quarantine-флаг. Технический пользователь может снять его командой:

```bash
xattr -dr com.apple.quarantine /Applications/FreeTypograf.app
```

Обычному тестировщику сначала лучше попробовать запуск через правый клик -> **Open**.
