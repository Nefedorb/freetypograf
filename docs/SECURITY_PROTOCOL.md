# Security Protocol

## Принципы

- Приложение обрабатывает текст только локально.
- Содержимое выделения, буфера обмена, входного и выходного текста запрещено писать в логи, настройки, crash reports и telemetry.
- По умолчанию telemetry отсутствует. Разрешены только локальные счетчики результата: количество замен, время операции, статус успеха или ошибки.
- Runtime не должен использовать сетевые API для типографирования.

## Clipboard Safety

- Перед типографированием UI сохраняет текущий текстовый буфер через clipboard-manager, если это возможно.
- После вставки результата UI пытается восстановить прежний текстовый буфер.
- Если буфер был пустым или недоступным, приложение не должно считать это критической ошибкой.
- Plain text является единственным поддерживаемым форматом MVP.
- Runtime-команды не принимают содержимое пользовательского текста и не должны добавлять такие аргументы без отдельного security review.

## WARNING: чувствительные данные

Clipboard-flow может временно читать чувствительный выделенный текст. Безопасная альтернатива в MVP:

- локальная обработка;
- отсутствие логирования текста;
- понятный режим паузы;
- отсутствие фонового мониторинга clipboard;
- явный first-run текст о том, что обработка запускается только действием пользователя.

## Windows

- Для вставки в активное приложение используется имитация системных сочетаний клавиш.
- Floating-окно должно использовать no-activate поведение, чтобы не красть фокус перед `Ctrl+C`.
- В elevated/admin-приложениях Windows ввод может быть заблокирован системной политикой. Это нужно показывать как понятную ошибку без повторных агрессивных попыток.

## macOS Later

- macOS-версия потребует Accessibility-разрешений.
- Приложение должно объяснять, зачем нужен доступ: отправить copy/paste по явному действию пользователя.

## macOS

- Copy/paste отправляются через `osascript` и `System Events`.
- Runtime не передает пользовательский текст в AppleScript: скрипт содержит только клавишу `c` или `v`.
- Для работы clipboard-flow пользователь должен вручную выдать Accessibility-разрешение приложению.
- При отсутствии разрешения приложение должно показывать понятную ошибку, а не повторять попытки агрессивно.

## Environment

- Запрещено использовать `NODE_TLS_REJECT_UNAUTHORIZED=0` как часть проекта.
- Перед `npm`, `pnpm`, `npx` командами в текущем окружении нужно сбрасывать эту переменную.
